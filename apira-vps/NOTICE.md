# Apira VPS Notice

Apira VPS is a modified distribution of the MIT-licensed WeVPS/VMTOOL project.

The original MIT license and copyright notice are preserved in `LICENSE`.

Changes in this distribution include user-facing rebranding, migration of package/update resources to the Apira VPS GitHub location, and replacement of the original external authentication dependency with server-local authentication.

Some internal identifiers remain unchanged for binary compatibility, including `vmtool.service`, compiled module filenames, extension IDs/routes, and selected `WEVPS_*` environment-variable names. These identifiers are implementation details and are not the public product brand.

This distribution does not claim authorship of upstream components that remain under their original copyright.
