Quick guide

Six steps to run your whole stack from here

01
Inspect your containers

Open Containers → View & interact: logs, stats and shell in one modal. Switch to the Inside container tab and click through files instead of typing paths — clicking a log file tails it instantly.

02
Track a repository

Git Repositories → add an absolute path containing .git. Review dirty files and diffs first, then Fetch or Pull with fast-forward-only protection.

03
Automate with scheduled tasks

Build a cron schedule without memorizing syntax and preview its next runs. Deleted tasks are archived automatically — bring one back anytime with Restore, or wipe it permanently with Delete forever.

04
Keep long jobs in screen sessions

Start a detached session for workers or watch jobs, read their live buffer and send commands from the panel. Sessions seen before stay saved in the database — enable, restart or forget them whenever you like.

05
Never miss a release

Add an Update Watcher per installed binary. OpsDeck checks GitHub, verifies checksums, backs up, replaces and runs your restart command — rolling back automatically if something smells like a downgrade.

06
Tune and audit

Set custom docker / git / screen binary paths, default log tail and a GitHub token in Settings. Every action you take shows up under Activity.

Nothing leaves this server. Commands execute locally through the installed CLIs, no credentials are stored, and destructive operations always require typed confirmation phrases.
