Apira VPS Resource Sentinel

Know before it breaks — thresholds that watch your server around the clock.

Resource Sentinel samples CPU, memory, swap, disks, network, load, temperature and processes on a fixed cadence, detects sustained breaches, and pushes alerts to Telegram and email with smart cooldowns and recovery notices.

Version 1.0.0
Maintained by Apira VPS
Metric engine psutil sampling

Eleven live metrics

CPU, RAM, swap, per-mount disk usage, disk read/write throughput, download/upload traffic, load average, thermal sensors and process count.

Sustained detection

Alerts fire only after a breach persists for the configured duration, with per-rule cooldowns that stop notification storms.

Secure by default

Panel authentication, CSRF protection, encrypted credentials and recovery notifications when conditions return to normal.

How Resource Sentinel protects your uptime

A clear path from metric to message

01 Collect

Sample all resources every few seconds into a rolling buffer.

02 Evaluate

Compare each enabled rule against the freshest sample.

03 Notify

Push formatted alerts to Telegram and email channels.

04 Recover

Close incidents and confirm recovery when values normalize.

Your server stays in control. Metrics are sampled locally, credentials are encrypted at rest, and nothing leaves the machine except the notifications you explicitly configure.
